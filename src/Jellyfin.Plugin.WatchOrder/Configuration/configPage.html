Watch Order Playlists

Playlists are rebuilt daily (and at server start) from arrowverse.info and aaronperris.com/mcu. Only items already in your library are added. To sync now: Dashboard → Scheduled Tasks → Sync watch-order playlists.

Users

Each ticked user gets their own private copy of each playlist. If none are ticked, the first administrator gets them.
Each user's playlists drop watched items from the front, so pressing Play continues where they left off. Something watched out of order further down stays in its place (shown as watched) until they get there. To skip an item on purpose, mark it watched; marking one unwatched moves the starting point back.

Playlists

Each order comes as a canon playlist and an Extended playlist, which adds the non-canon entries the guide lists (older Fox and animated series, etc.).

Built-in lists

Watch orders shipped with the plugin, for franchises without an online guide. With a Backup data URL set, they update automatically; otherwise they update with plugin releases.
Leave blank unless you run your own backup. When set, the daily sync also picks up updated built-in lists from it (no plugin update or restart needed), and it's used as a fallback when a guide site is down or looks broken. A copy of each guide and list is always kept on this server.

Series aliases (optional)

Only needed if a show you own is listed under Missing from your library because its name differs. Pick the name the guide uses on the left and your show on the right; both boxes suggest names as you type. Add a year to the right-hand name, e.g. Doctor Who (2005), to pick one of several shows with the same name.

Missing from your library

What the ticked playlists include that isn't in your library, based on the guides saved at the last sync. Fix a misnamed show with a Series Alias, save, and it drops off this list. Movie titles aren't shown, only counts.
