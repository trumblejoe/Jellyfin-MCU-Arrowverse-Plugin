# Guide data backup

Maintained automatically by the "Update guide data" workflow on `main`. The
Watch Order Playlists plugin falls back to these files if a guide site is unavailable.

Data comes from, and all credit goes to:
- https://arrowverse.info/
- https://aaronperris.com/mcu/ (by Aaron Perris)

The files keep only what the plugin needs for ordering: show names, season and episode
numbers, dates, order positions, and movie titles. They contain no episode titles or
synopses.
